# Mimi portfolio

A simple, responsive portfolio landing page for visual creative work. It uses plain HTML and CSS, so there are no dependencies or build steps.

## Edit the page

- Open `index.html` to change the introduction, project names, descriptions, and contact details.
- Open `styles.css` to adjust colors, type, and spacing. The palette is defined near the top under `:root`.
- Replace the labeled image placeholders with `<img>` elements using descriptive `alt` text, and put optimized images in an `images/` folder. For video work, link a card to a video or case study when ready.
- Replace the sample project titles and contact placeholder before sharing the site.

Preview locally by opening `index.html` in a browser. For a local server, run `python3 -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the publishing branch (usually `main`), choose `/ (root)`, and save.
5. GitHub will show the published URL on the Pages settings screen. Updates to that branch will republish the site.

No deployment has been configured by this repository.
